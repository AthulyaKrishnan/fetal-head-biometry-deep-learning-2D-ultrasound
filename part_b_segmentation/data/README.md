# Part B data (not tracked)

```
data/
├── images/        # ultrasound images: NNN_HC.png
└── annotations/   # ground truth, one file per image: NNN_HC_Annotation.png  (1-pixel ellipse outline)
```

The `_Annotation` suffix is the default `--gt_suffix`. Ground truth is an ellipse outline, not a filled mask;
`tools/prepare_data.py` fills it and excludes outlines that cannot be closed (2 of 622 in the reported run).

Source: the file naming (`NNN_HC.png`, `NNN_HC_Annotation.png`) and the optional `--pixel_csv` follow the HC18 challenge data, and the same 622 images are used in Part A (Multicentre Fetal Biometry benchmark, https://github.com/surgical-vision/Multicentre-Fetal-Biometry). Confirm the exact source, licence and citation before publishing.

Generated by the scripts (also not tracked), all relative to `part_b_segmentation/`:

| Folder | Created by | Contents |

| `reports/` | `tools/check_dataset.py` | dataset quality report |

| `eval_full/<name>/` | `scripts/evaluate.py` | per-image metrics, biometry points, summary, predicted masks, worst-case overlays |

| `predictions/` | `tools/predict.py` | masks and ellipse measurements for new images |
| `results/` | `scripts/test.py` | evaluation on an external test set |
